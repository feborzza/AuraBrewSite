# AuraBrew — Apresentação do Projeto Acadêmico

Este repositório reúne a página de apresentação do projeto <strong>AuraBrew</strong>, desenvolvido pelo grupo Engenheirando no contexto de Engenharia de Produção e Engenharia de Computação. O site descreve o desenvolvimento de um sistema de monitoramento de temperatura para produção artesanal de cerveja, o gerenciamento do cronograma e os resultados da equipe.

## Objetivo

O objetivo principal desta entrega é demonstrar o desenvolvimento integrado de um protótipo de sensor IoT para controle térmico durante a fermentação, associado a um dashboard web de acompanhamento em tempo real e a documentação didática do processo.

## Conteúdo do projeto

- Página web desenvolvida em **React** + **Vite**
- Seção de apresentação do projeto e conceito de marca
- Descrição do sistema de sensor de temperatura com **ESP32** e **DS18B20**
- Cronograma em **Gráfico de Gantt** para visualização de atividades
- Plano de gestão **5W2H** com responsabilidades e status
- Etapas da produção artesanal de cerveja
- Dashboard de monitoramento e fluxo de dados
- Link para mini jogo associado ao universo da marca
- Apresentação da equipe envolvida

## Tecnologias utilizadas

- **React 18**
- **Vite**
- **JavaScript**
- **CSS moderno**
- **HTML5**

## Como executar

1. Instalar dependências:

```bash
npm install
```

2. Iniciar o servidor de desenvolvimento:

```bash
npm run dev
```

3. Abrir o navegador em:

```bash
http://localhost:5173
```

## Estrutura de arquivos

- `index.html` — template HTML principal
- `src/main.jsx` — entrada do aplicativo React
- `src/App.jsx` — componente principal e conteúdo das seções
- `src/App.css` — estilos visuais do site
- `public/` — imagens e ativos estáticos
- `package.json` — informações de dependências e scripts

## Observações acadêmicas

A organização do projeto prioriza a clareza expositiva, visando tornar a apresentação acessível tanto para avaliadores quanto para não especialistas.
